🚀 Project Overview
MyrentAbuja is a user-friendly platform designed to connect tenants and landlords directly — no middlemen involved! Landlords can list properties 🏢, and tenants can browse available rentals 🏡, book viewings, and communicate — all in one seamless app.

✨ Features
👤 User Roles
Landlord

Tenant

🏠 Landlord Features
Secure registration: name, DOB, email, NIN, phone, address, and passport photo 📝

Profile dashboard with personal info overview

Property management:

List new properties with location and documents 📍📄

Upload land ownership certificate linked to unique token ✔️

Mark properties as Occupied or Vacant 🔒 / 🔓

Track lease duration and rent expiration ⏳

View all owned properties with status updates

Built-in messaging system to chat directly with interested tenants 💬

Prompt to add properties if none are listed

🔎 Tenant Features
Register with personal details: name, DOB, marital status, phone, email, and password 🔐

Browse all available properties on a clean dashboard

Powerful filters: price range, apartment type, and location 🎯

View property cards showing price, photos, and location 🖼️📍

Detailed property pages with “Chat with Landlord” button 💬

Chat interface only visible during active conversations, with profile access for both parties

“My Apartment” section showing current rental and lease status 📅

⚙️ Common Features
Splash screen before login 🎨

Separate signup for tenants and landlords 👫

Payments handled offline for now (coming soon!) 💵

🔐 Admin & Developer App
Verify submitted documents & ownership certificates before properties go live ✅

Approve property listings for tenant visibility 👀

Full access to user data and system management 🛠️

Backend handles authentication and permissions 🔑

Prerequisites:

Node.js (v14+)

MongoDB (running locally or cloud)

# Navigate into project folder

# Create .env file and configure environment variables (DB connection, JWT secret, etc.)

# Start the app
